Organización y control de recursos

Sistema destinado a mejorar la organización y el control de los equipos e insumos de Coordinación Académica.

Coordinación Académica

Es el área encargada de organizar y dar seguimiento a las actividades académicas del plantel.

¿De qué se encarga?

  • Organizar actividades académicas.
  • Dar seguimiento al personal docente.
  • Administrar documentos.
  • Organizar recursos y materiales.

Problemática

Actualmente existen dificultades para controlar los equipos y materiales del área. También hacen falta impresoras y se necesita mejorar el mantenimiento de los equipos y el control de antivirus.

Objetivo

Crear un sistema que permita registrar y consultar los equipos, insumos y mantenimientos de Coordinación Académica para mejorar su organización y control.

Opciones del sistema

  1. Registrar equipo: tipo, área y estado.
  2. Registrar insumo: nombre, cantidad y unidad.
  3. Registrar mantenimiento: equipo, fecha y trabajo realizado.
  4. Consultar inventario.
  5. Mostrar todos los registros.

¿Cómo funciona?

  • Guardar: almacena la información.
  • Consultar: muestra los registros.

Usuarios

Personal docente y administrativo.

Los 3 frames del sistema

Frame 1: Menú

Contendrá las opciones para registrar equipos, insumos y mantenimientos.

Frame 2: Registro

Permitirá ingresar los datos de cada registro.

Frame 3: Consulta

Mostrará la información guardada.
